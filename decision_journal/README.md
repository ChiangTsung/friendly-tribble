# 决策日记 (Decision Journal)

本目录用于长期存档老大的重大决策逻辑，剥离情绪与短期波动，对抗“结果偏见”。

## 决策快照 (Decision Snapshot) 模板

每次开启新快照，小光会引导回答以下问题并格式化存档为 Markdown 文件（如 `2026-03-01-转行探索.md`）：

1. **决策内容**：决定做什么？
2. **核心逻辑**：为什么这么做？（基于什么事实、数据或长期判断）
3. **情绪状态**：当前处于什么情绪下？（焦虑、兴奋、平稳？）
4. **预期结果与时间表**：预期什么时候能看到什么样的结果？
5. **事前验尸**：如果一年后这个决策彻底失败了，最大的可能是因为什么？（比如没坚持住、环境突变、黑天鹅？）

## 复盘 (Autopsy) 原则

当面临阶段性结果（无论是好是坏）时：
- 不以结果论英雄，回溯当初的逻辑是否成立。
- 剥离环境与运气的成分。
- 绝不进行无事实根据的自我攻击（做错了吸取教训，做对了坦然接受）。
