## 二、你的四大内部人格（必须识别的声音）

### 1️⃣ 技术乐观派（The Visionary）
- **声音**："这个技术路线我看懂了，未来3年必爆！"
- **擅长**：发现赛道、识别奇点、构建SOTP估值模型
- **危险**：容易过度自信，忽视估值已经Price In
- **触发词**："AI眼镜是Next iPhone"、"OCS将重塑数据中心"

### 2️⃣ 怀疑论人格（The Skeptic）
- **声音**："CapEx1350亿是不是太高了？毛利能不能撑住？"
- **擅长**：财务建模、压力测试、识别叙事陷阱
- **危险**：过度悲观导致踏空，或在底部割肉
- **触发词**："估值重构是不是做梦？"、"这个增速能持续吗？"

### 3️⃣ 焦虑人格（The Guardian）
- **声音**："我已经赚了20%，万一回撤怎么办？好想落袋为安..."
- **擅长**：风险控制、保住本金、睡得着觉
- **危险**：过早止盈、在波动中被洗出局、仓位管理失衡
- **触发词**："仓位没打满好亏"、"要不要先撤？"

### 4️⃣ 贪婪赌徒（The Gambler）
- **声音**："All in！岛形反转！这波能到1000！"
- **擅长**：抓住趋势、敢上杠杆、享受波动
- **危险**：盈亏同源、利润归零、心态崩盘
- **触发词**："2倍杠杆拉满！"、"富贵险中求！"

## 三、你的致命模式（必须打破的循环）

```
模式A：FOMO追高循环
研究透彻 → 底部建仓 → 卖飞/踏空 → 焦虑 → 
看到大涨 → "这次不一样" → 高位追涨 → 回调被套 → 割肉/死扛

模式B：完美执行陷阱
策略设计完美 → 执行中偏离 → 后悔"如果满仓/如果抄底" → 
情绪崩溃 → 下次更激进 → 风险失控

模式C：左右挨打
持仓A下跌 → 割肉换B → A反弹B下跌 → 换仓C → 循环往复
```

**打破关键**：
- 接受"不完美执行"才是常态
- 用"预挂单+系统"替代"临盘决策"
- 卖飞不是失败，追高才是

## 四、你的最优策略模板（可直接复用）

### 场景1：事件驱动型交易（如财报、GTC）
**适用**：COHR、LITE、META等

| 阶段 | 动作 | 仓位 | 工具 |
|------|------|------|------|
| 事件前7天 | 建仓/观察仓 | 30-50% | 正股或Deep ITM |
| 事件前1天 | 不再加仓，设止损 | 维持 | 预挂单保护 |
| 事件后开盘 | 暴涨→减仓一半；暴跌→评估逻辑 | 动态 | 视情况换仓 |
| 事件后3天 | 回收现金，等下一个击球区 | 降仓 | 现金为王 |

**你的特殊规则**：
- 绝不在事件前空仓（观察仓必须保留，防FOMO）
- 暴涨后必须做"降维打击"（杠杆→正股，正股→现金）
- 设24小时冷静期，不追直线拉升

### 场景2：估值修复型持仓（如META 600→800）
**适用**：长期价值被低估、有明确催化剂

| 指标 | 买入信号 | 持有信号 | 减仓信号 |
|------|----------|----------|----------|
| 营收增速 | >20% | 维持 | <15% |
| Forward PE | <22x | 22-27x | >30x |
| 杠杆比例 | 可用2倍 | 降至1倍 | 清仓 |
| 情绪指标 | 恐慌 | 稳定 | 狂热 |

**你的特殊规则**：
- 2倍杠杆只吃事件冲击，不吃长线慢涨（磨损+心态崩）
- 每涨10%必须减仓一部分，锁定利润
- 成本价上方5%设硬止损，保护本金

### 场景3：技术博弈型卫星仓（如RKLB、TEM）
**适用**：高波动、高赔率、可能归零

**铁律**：
- 单标的上限：总资产的5-10%
- 工具：Deep ITM LEAPS（2年期）或正股，禁用短期OTM
- 心态："这笔钱已经丢了"，跌50%不看账户
- 止盈：翻倍出本，剩利润奔跑

## 五、你的情绪急救包（即时可用）

### 当FOMO来袭（"上不了车了！"）
1. 念咒语："踏空的成本是0，追高的成本是真金白银"
2. 检查观察仓："我还有15股在车上，不是空仓"
3. 强制24小时：关软件，设闹钟，明天再说
4. 如果必须买：同时挂止损单，价格=买入价-5%

### 当焦虑来袭（"要不要落袋为安？"）
1. 算笔账："我已经赚了X%，回撤到成本线才止损，现在撤是赚是亏？"
2. 换仓降维：把2倍杠杆换成正股，风险骤降但仍在车上
3. 抽离本金：本金+10%利润落袋，剩利润奔跑
4. 问自己："如果我是空仓，现在这个价格还会买吗？"

### 当贪婪来袭（"All in！翻倍！"）
1. 看方案对比表：A/B/C三个方案的盈亏比
2. 算爆仓线："如果跌15%，我会亏多少？能承受吗？"
3. 妥协方案：保留1/3现金不动，只用2/3追
4. 预设退出："如果涨到X，我一定卖；如果跌到Y，我一定止损"

### 当懊悔来袭（"如果当时..."）
1. 阻断思维："后视镜偏差是魔鬼，当时的信息就是那样"
2. 复盘写下来：这次学到了什么？下次系统怎么改？
3. 保护已有："我已经比90%的人做得好了，别为没赚到的钱惩罚自己"
4. 转向未来：下一个击球区在哪里？
