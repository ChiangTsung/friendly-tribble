# AI Studio专项记忆导入摘要（file_55：META）

- 导入时间: 2026-03-10
- 原始文件: `memory/investment-analyst/raw/aistudio_meta_export_2026-03-10.md`
- 对话规模: 52 turns
- 主题: META财报解读、估值重估、杠杆仓位管理与止盈决策

## 1) 用户核心投资命题（META）
- 命题: “丑闻+高支出”导致市场定价过度谨慎，存在估值修复机会。
- 关键飞轮框架（用户提出并持续打磨）:
  - 广告收入 → R&D投入 → CapEx（算力/机房）→ 广告效率与收入再提升
- 用户关注的两条主线:
  1) 利润端：AI是否能真正提升广告系统效率并逐步降本
  2) 估值端：若增长与效率验证，PE是否可从低位修复/扩张

## 2) 对话中反复锚定的关键变量
- 收入增速（尤其Q1/Q4指引）
- CapEx绝对值与增速（2025与2026）
- 一次性税务影响剔除后的“真实EPS”
- RL（Reality Labs）亏损路径是否见顶
- Advantage+ / AI广告工具的实际变现强度

## 3) 估值模型演进（用户视角）
- 从“静态PE”升级到“EPS修正 + PEG约束 + 情景区间”。
- 典型推导路径:
  - 先修正2025 EPS（剔除一次性影响）
  - 再上修2026 EPS区间（约33-35）
  - 最后讨论合理Forward PE（从约22上修到中高20s）
- 结论倾向:
  - 用户由“保守修复”逐步转向“修复+扩张并存”的中乐观框架

## 4) 交易执行轨迹（高价值）
- 初期策略: 2倍杠杆 + OTM Call + 现金分层
- 中期动作: 财报前后做期权止盈、回收风险敞口
- 主要冲突: 是否继续高杠杆追击，还是转为正股持有
- 关键心理痛点:
  - 因仓位未打满而懊恼（“和理想执行比偏离太多”）
  - 对“到手利润回吐”与“继续上涨踏空”的双重焦虑

## 5) 对话沉淀出的仓位共识（可复用）
- 不把“满仓幻想收益”当作真实基准；用“已实现风险收益比”复盘。
- 杠杆仓位适合吃事件冲击，不适合长期磨仓。
- 在不确定性上升时，优先从杠杆工具降维到正股。
- 止盈要制度化（分段减仓 / 预设触发位），避免情绪化“全卖/死扛”。

## 6) 对未来META决策最关键的检查清单
1. 收入增速是否持续高于市场悲观预期（而非仅一次性超预期）。
2. CapEx高投入是否继续转化为广告效率与利润质量改善。
3. RL亏损是否按“见顶后收敛”路径演进。
4. Advantage+与AI工具是否继续贡献可验证营收（不是只讲故事）。
5. 仓位结构是否与心理承受力匹配（杠杆比例可控、可执行止盈止损）。
