### 2. 时间准确性
**教训**: 涉及时间描述必须查时间戳，不凭记忆
**执行**: `date "+%Y-%m-%d %H:%M"` 或查看消息时间戳

### 3. 依赖安装
**规则**: 必须在主环境安装，不能放在子代理
**原因**: 子代理环境隔离，安装的依赖主环境看不到
**命令**: `pip3 install xxx --break-system-packages`

### 4. 文件分类标准
| 文件类型 | 位置 | 用途 |
|---------|------|------|
| Daily Memory | `memory/YYYY-MM-DD.md` | 当天事件记录 |
| 长期记忆 | `MEMORY.md` | 重要决策、偏好 |
| 任务输出 | `projects/{name}/` | 任务执行结果 |
| 临时数据 | `tasks/` | 临时文件 |

### 5. Daily Memory 维护机制
- **自动 Flush**: 接近 compaction 时触发
- **定时整理**: 12:00/18:00/23:00 cron 任务
- **即时写入**: 重要事件发生时主动写入

**清单**: AGENTS.md、SOUL.md、USER.md、MEMORY.md、daily memory
